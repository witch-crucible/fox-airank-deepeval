请在以 **runs 下**当前模型命名的文件夹 实现一个“鹈鹕骑自行车处理障碍”的动画项目。

背景约束：

不要参考本项目下其他代码，从新实现

技术约束：
允许使用 TypeScript 和 SVG。
允许进行验证。
不得调用图像生成工具，不得下载现成图像、SVG、角色模型或动画素材。

功能要求：

1. 画布为 960×640，正侧视，自行车朝右。
2. 自行车结构完整，车轮、曲柄、踏板和腿部运动同步。
3. 鹈鹕具有长喙、喉囊、两条关节腿，至少一只翅膀接触车把。
4. 两只脚持续接触对应踏板。

障碍系统：

1. 实现地面石头障碍。
2. 实现天空掉落物障碍。
3. 障碍必须通过统一的时间状态或事件系统调度，而不是零散写死动画。
4. 鹈鹕/自行车在接近石头时必须减速绕行或越过。
5. 天空掉落物必须具有可测量的下落轨迹。
6. 鹈鹕必须对掉落物做出躲避或停车反应。
7. 在组合事件阶段，系统必须同时处理石头和掉落物，而不破坏脚踏和车把关系。
